# Продукт и границы MVP

TradeGuard — помощник начинающего активного трейдера, фокус: фьючерсы и риск. Пользователь описывает идею, получает осмысленные уточнения, проверку оснований, программный расчёт и предварительный план. Затем исправляет и подтверждает версию; система проверяет согласованные условия, объясняет изменение и оставляет решение пользователю.

Demo Day: диалог → данные MCP → риск на спецификации → черновик → подтверждение версии → проверка → уведомление со ссылкой на условие/данные/время. При нехватке источников показывается неопределённость. Нет авто-заявок, универсального прогноза, поддержки любых стратегий, полноценного терминала или сложной инфраструктуры.

Ценность — осознанность и предотвращение критических ошибок. Снижение убытков/рост удержания не доказаны. Исходная оценка диалогов 2/3 не означает доходность или готовность проверенных торговых планов. Текущая реализация доходит до диалога и условной арифметики; следующие шаги — CP2/CP3, не скрытые функции готового продукта.
