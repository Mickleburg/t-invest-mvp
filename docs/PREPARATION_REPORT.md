# Итоги подготовки TradeGuard

21 ноября 2026. По уточнённому требованию пользователя завершён переход к frontend/backend/contracts/infra/docs. Старые прототипы больше не входят в рабочую директорию. Новые продуктовые функции не разрабатывались.

## Изменено

- Диалог/промпт перенесены в backend/app/agent; сменный LLM binding и MCP/CLI — в llm.
- T-Invest MCP, поиск инструментов, значения, секреты и Chromium research — в integrations; Decimal-риск — в risk; SQLite — в storage.
- API/DTO — в api; main.py собирает один backend без UI. Frontend — отдельное приложение.
- plans/monitoring содержат контракты будущих модулей без фиктивной реализации.
- Проверки контрактов — backend/scripts, тесты — backend/tests, зависимости/pytest.ini — backend, пример окружения — infra.
- Старые пакеты, отдельные тесты/фикстуры/данные прототипов, PDF/скриншоты/отчёты и экспериментальные скрипты убраны из рабочей директории. Runtime нового MVP и venv перемещены внутрь backend без копирования.
- Обновлены Dockerfile, ignore-файлы, инструкции и владение. Импортов старых пакетов нет.

## Проверено

26 актуальных offline-тестов прошли: риск/единицы/лотность/фьючерсная спецификация, поиск, ошибки источников, история/идемпотентность, educational-контекст, сменный LLMProvider, API-only, схема/примеры планов, отсутствие drift и импортов старых прототипов. Удалённые тесты прежних приложений не выдаются за проверки текущего MVP.

OpenAPI, JSON Schema и примеры валидны, дрейфа HTTP-контракта нет. Все 34 модуля backend импортируются. Frontend syntax check и Compose config прошли. Backend запущен на 8003, frontend на 5173; health через оба адреса вернул 200. Chromium smoke на ширине 1365 и 390 px: чат загружается, поле ввода видно, горизонтального переполнения нет, ошибок JavaScript и HTTP нет. Это проверка загрузки интерфейса и API, без отправки запроса реальной LLM.

Проверено точное содержимое корня: пять каталогов frontend/backend/contracts/infra/docs, README.md, AGENTS.md, AGENT.md, .gitignore и .dockerignore. Кодировка документов UTF-8 проверена.
