# Исходное состояние и решение о миграции

21 ноября 2026. До подготовки существовали карточка ThesisGuard (8000), агент наблюдений (8001), диалог TradeGuard (8002). Первоначальный прогон: 182 passed; после архитектурных проверок: 192 passed, включая старые приложения. Это исторические результаты, не количество тестов текущего проекта.

Первоначально сохранялись старые пакеты и совместимые точки входа. Затем пользователь прямо потребовал убрать всё, что не относится к обновлённой архитектуре. Это заменяет прежнее требование хранить старые прототипы в рабочей директории.

## Переход

Использовавшиеся диалог/модели/промпт, MCP/LLM-мост, read-only T-Invest transport, Chromium research, SQLite и Decimal-риск перенесены в backend/app. Из карточного PoC взяты только нужные функции идентификации инструментов и чтения значений. Единственный frontend — frontend/src. Старые точки входа 8000–8002 больше не поддерживаются.

Старые приложения, их отдельные тесты, фикстуры, отчёты/PDF, скриншоты и экспериментальные скрипты убраны за пределы рабочей директории. Данные нового MVP перемещены из data/mvp в backend/runtime без копирования и изменения схемы. Окружение перемещено в backend/.venv. Внешнее хранилище токена не менялось.

Перед переносом серверы остановлены. Базы разных прототипов не объединялись. Внутри проекта нет архивной копии старых реализаций и дублирующих сервисов.

## Git и ограничения

git status и git rev-parse сообщают not a git repository; HEAD и достоверный tracked/untracked diff отсутствуют. Git init, коммиты, теги и изменение истории не выполнялись.

Перенос не устраняет ограничения исходного механизма: таймауты MCP, блокировки веб-источников, зависимость Codex CLI, сырой evidence, неверсионированный Reply.plan. Подтверждение и мониторинг нового TradePlan отсутствуют. Качество внешних данных реорганизацией не доказано.
