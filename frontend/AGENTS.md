# Frontend — разработчик 1

Соблюдать корневой AGENTS.md. Единственный источник UI — frontend/src/. Общение с backend только через HTTP /api/, без импорта Python и без брокерских/LLM-токенов.

Сверяться с contracts/openapi.yaml: implemented работает сейчас, planned — будущий контракт. Примеры contracts/examples/ — явные учебные моки. Различать черновик, подтверждённую версию, неизвестные данные, ошибку источника и доставленное уведомление. Подтверждение не размещает заявку.

Не менять backend и общие контракты без согласования. Проверка: `npm --prefix frontend run check`; браузерный smoke чата, ошибок, истории и мобильной ширины. Запуск: `npm --prefix frontend run dev`, backend на 8003. Не исправлять пользовательские сообщения ради скриншота.
