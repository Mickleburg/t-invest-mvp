# Frontend — разработчик 1

Соблюдать корневой AGENTS.md. Единственный источник UI — frontend/src/. Общение с backend только через HTTP /api/, без импорта Python и без брокерских/LLM-токенов.

Сверяться с contracts/openapi.yaml: все операции v0.2 implemented, статус контракта provisional. cp6.js — редактор плана и мониторинг; app.js — диалог. Использовать серверный ETag для подтверждения, не считать риск в JavaScript. Несохранённые правки не перетирать фоновым polling. Примеры contracts/examples/ — явные учебные моки. Различать draft, confirmed snapshot, отсутствие данных и stored/delivered. Подтверждение не размещает заявку. Новые коммиты и описания — на русском от пользователя.

Не менять backend и общие контракты без согласования. Проверка: `npm --prefix frontend run check`; браузерный smoke чата, ошибок, истории и мобильной ширины. Запуск: `npm --prefix frontend run dev`, backend на 8003. Не исправлять пользовательские сообщения ради скриншота.
